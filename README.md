# Pixel Painter


This site showcases the Pixel Painter project, an interactive pixel art drawing application with various features to enhance the user experience.

## Live Demo

→ [Pixel Painter](https://pedroalves-dv.github.io/pixelpainter/)
[./assets/pixelpainter-screenshot.jpg](https://pedroalves-dv.github.io/pixelpainter/)

## Features

### 🖌️ Interactive Canvas

- An interactive canvas where users can draw pixel art. Supports click and drag.

### 📐 Grid Customization & Presets

- Users can customize the height, width of the grid, the size of the pixels or choose a preset.

### ↩️ Undo / Redo / Clear

### ↩️ Zoom In & Out / Pan & Reset Position

### 🎨 Color Palette

- Select and apply colors to individual pixels.

### ↩️ Show / Hide Grid Toggle

### 💾 Export Function

- Users can export the canvas as both a jpg and png file.

## Technologies Used

- **HTML**: For structuring the content.
- **CSS**: For styling the website.
- **JavaScript**: For interactive features and dynamic content.
- **LocalStorage**: For persisting user preferences and drawing progress.

## Getting Started

1. Clone the Repository

```sh
 git clone https://github.com/pedroalves-dv/pixelpainter.git
 cd pixelpainter
```

2. Open `index.html`

Simply open the `index.html` file in your preferred web browser.
